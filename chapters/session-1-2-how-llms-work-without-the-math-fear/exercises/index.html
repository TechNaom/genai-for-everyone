Session 1.2 Exercises 15 min, hands-on

Exercise: Tokenizer Playground

Build real intuition for how text gets split into tokens — and see, hands-on, why some languages and word choices cost more tokens than others.

How to run these Install the free, local tokenizer with pip install tiktoken, then download starter.py below and run python starter.py from a terminal. No API key needed.
starter.py solution.py (reference)

1 Predict before you run

Open starter.py. For each sentence in the SENTENCES list, fill in your_guess with how many tokens you think it will become — before running the script. Predicting first is the whole point.

2 Run and compare

Run python starter.py. It prints each sentence next to your guess, the actual token count, and a visualization of exactly where each token split.

3 Answer the reflection questions

The script prints three reflection questions — the biggest guess/actual gap, the Hindi vs. English cost implication, and whether supercalifragilisticexpialidocious splits into meaningful parts. Answer them in the comment block at the bottom of starter.py.

What you'll notice Common English words are often single tokens; rare or made-up words get split into pieces. The same sentence in Hindi or Japanese often uses more tokens than the English equivalent — and since APIs bill per token, that difference is a real cost difference.
