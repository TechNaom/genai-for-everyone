Session 1.5 Exercises 15 min, hands-on

Exercises: Hallucination Detection

Build the habit of spotting likely hallucinations by looking for the RIGHT signals — not confidence or fluency (both are useless here), but specificity that can't be verified and suspiciously convenient details.

How to run these Download starter.py below, then run python starter.py. No API key needed — this runs entirely offline.
starter.py solution.py (reference)

1 Classify all 10 statements

Open starter.py. For each statement in STATEMENTS, set your_classification to "accurate" or "fabricated".

2 Write your reasoning

For each one, fill in your_reasoning with ONE sentence naming the signal that led you there. Then run the script to see your calls laid out.

3 Compare against the ground truth

Run python solution.py. Some accurate-sounding statements are fabricated, and some "suspiciously specific" ones are actually true — this exercise is humbling on purpose.

What you'll notice Every statement is written in the same confident tone, true or false — so confidence and fluency tell you nothing. The real signal is whether a specific detail can be independently verified, or whether it just sounds like the kind of thing that could be.
