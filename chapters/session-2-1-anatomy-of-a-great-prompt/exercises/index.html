Session 2.1 Exercises 15 min, hands-on

Exercises: Prompt Rewrite Exercise (Bad → Great)

Build the habit of diagnosing exactly which pillar — clarity, context, constraints, format — is missing from a weak prompt, then fixing it deliberately, not just making it "sound nicer." This is a pure prompt-design and reasoning exercise: no API calls, no paid keys, just plain Python that runs anywhere.

How to run these You'll need Python 3 installed (check with python --version). Download starter.py below, then run it from a terminal with python starter.py. It prints each weak prompt and flags any entry you haven't filled in yet.
starter.py solution.py (reference)

The task

Open starter.py. For each of the 5 weak prompts in WEAK_PROMPTS, fill in three fields. The test for each rewrite: could a competent person, given ONLY your rewritten prompt, produce something close to what's actually needed, without guessing at anything important?

1 Diagnose the missing pillars

Set missing_pillars to a list containing any of "clarity", "context", "constraints", "format" — whichever ones this weak prompt is genuinely missing. Some prompts are missing all four.

2 Rewrite it

Set rewritten_prompt to your improved version. Invent any reasonable specifics you need (an audience, a business, a length) — the point is that your version closes the gaps you just diagnosed.

3 Justify the change

Set why_better to one sentence explaining what changed and why it matters. Re-run the script after each edit — it counts how many prompts remain unrewritten.

🐞 Task 4 — Debug the Code

A teammate diagnosed this prompt but the script prints WARNING: unrecognized pillar(s) instead of accepting the row. Only four pillar names are valid. Find the bug and fix the missing_pillars list so it validates cleanly.

starter.py 
WEAK_PROMPTS = [
    {
        "weak_prompt": "Write a blog post about productivity.",
        "missing_pillars": None,     # TODO: e.g. ["context", "constraints", "format"]
        "rewritten_prompt": None,    # TODO
        "why_better": None,          # TODO
    },
    # ... 4 more weak prompts ...
]


def review():
    incomplete = 0
    for i, item in enumerate(WEAK_PROMPTS, 1):
        if item["missing_pillars"] is None or item["rewritten_prompt"] is None:
            incomplete += 1

Checking your work There's no automated grader — that's intentional. Several of these prompts could reasonably be missing a slightly different combination of pillars depending on how you read them. The goal isn't perfect agreement with solution.py; it's being able to defend your diagnosis and your rewrite. Compare your reasoning against solution.py (run it with python solution.py) once you've made a genuine attempt.
