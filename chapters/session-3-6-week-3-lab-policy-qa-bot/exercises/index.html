Session 3.6 Exercises 60–75 min, hands-on

Exercises: Build the Campus Student Services Q&A Bot

Integrate everything from Week 3 into one working system that retrieves across four separate, cross-referencing campus PDFs instead of one clean handbook: a Registration Guide, a Financial Aid Handbook, an Academic Standing Policy, and a Housing Handbook. The scaffold marks every place that integrates this week's concepts with # TODO markers — and Part 4 hands you a real, reproducible retrieval bug to diagnose and fix yourself, not just a function to fill in.

How to run these You'll need Python 3 installed (check with python3 --version), plus pip install pypdf to read the campus PDFs. Download starter.py below and place it alongside the included campus_docs/ folder (four PDFs, already provided — don't edit them). Run python3 starter.py to work through offline_test(), which needs no API key for Parts 1–4. To see live, citation-grounded model answers on genuinely unanswerable questions too, set ANTHROPIC_API_KEY and try the full pipeline end-to-end.

The tasks

1 Load and chunk the corpus

Find load_documents() and its # TODO. Load every .pdf in campus_docs/ with PdfReader, extract each page's text joined with "\n", and return {filename: full_text}. Then fill in chunk_text(): split on blank lines with re.split(r"\n\s*\n", text), accumulate paragraphs into a buffer until target_words is reached, close the chunk, and carry the last overlap_words words forward — the same paragraph-aware approach from Session 3.3.

2 Build the corpus and the vector store

Find build_corpus_chunks() and its # TODO. Flatten every document's chunks into a single list of {"doc": filename, "text": chunk_text} dicts across all four PDFs. Then fill in CampusVectorStore.__init__() (vectorize every chunk on construction) and .search() (score every entry by cosine similarity, sort descending, return the top k).

3 Citation-grounded generation

Find format_context(), build_rag_prompt(), and extract_citations(). Number each retrieved chunk [1], [2], ... tagged with a human-readable source label ("housing_handbook.pdf" → "Housing Handbook") — and don't leak the similarity score into the output. Build a prompt that requires every sentence to end with a citation marker and instructs the model to say plainly when it can't answer from the context. Then wire answer_question() together: search, format, prompt, call the model, extract citations, and resolve which source documents were actually cited.

4 Diagnose and fix the chunking bug

Once Parts 1–3 pass, the Part 4 check will almost certainly fail: both "What is the maximum course load for a student on probation?" and "What happens if I drop below full-time enrollment while living in a dorm?" retrieve registration_guide.pdf instead of the correct document. Don't jump to a fix. First print the chunks for registration_guide.pdf and notice there's suspiciously few of them. Try a few different target_words values and confirm the boundary never moves — proof the bug is upstream of chunk size. Then print repr(text[:300]) and look at how the real extracted text is structured. Only then write chunk_text_by_caps_header(), splitting on lines that are entirely uppercase, and confirm both questions now retrieve the right document.

5 Compare baseline vs. fixed across every question

Run every test question in offline_test() against both build_corpus_chunks() (baseline) and build_corpus_chunks_fixed() (caps-header). Confirm the fix resolves both known bugs without regressing any of the questions that already worked — a chunking change should be verified across the whole corpus, not just the two questions it was written to fix.

🐞 Task 6 — Debug the Code

This citation extractor is supposed to return the sorted, unique list of citation numbers in an answer, but it's returning duplicates in the original order instead of a clean sorted set. Find and fix the bug.

buggy_citations.py 
import re

def extract_citations(answer_text):
    matches = re.findall(r"\[(\d+)\]", answer_text)
    return [int(m) for m in matches]

print(extract_citations("Aid is disbursed within 10 days [1]. The deposit is $200 [2][2]."))
# prints [1, 2, 2] -- should print [1, 2]

Hint: the list comprehension keeps every match in the order it was found, duplicates included. Route the matches through a set() before converting back to a sorted() list.

Checking your work There's no automated grader — that's intentional. Run python3 starter.py and confirm all four parts of offline_test() pass, including the Part 4 assertions that baseline chunking retrieves the wrong document and fixed chunking retrieves the right one.
