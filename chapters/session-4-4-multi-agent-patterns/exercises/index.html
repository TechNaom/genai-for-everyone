Session 4.4 Exercises 25 min, hands-on

Exercises: Writer + Critic Two-Agent Loop

Build the smallest possible multi-agent system: a writer agent that drafts an essay, a critic agent that reviews it and returns feedback (never a rewrite), and the writer revising once based on that feedback. This is the Core Path build for this session — the Reviewer pattern from the lesson, at its simplest.

How to run these This exercise makes real model calls, unlike some earlier weeks' fully-offline exercises — that's deliberate, since the point is seeing the writer's output actually change in response to the critic's feedback. You'll need Python 3, the anthropic package (pip install anthropic), and an ANTHROPIC_API_KEY set in your environment. Download starter.py below, then run python starter.py.
starter.py solution.py (reference)

The task

Open starter.py. The overall loop structure is already scaffolded; three TODO sections are left for you to complete.

1 Write the writer agent's prompt

writer_agent() needs two prompt variants: one for the initial draft (write a clear, engaging essay on the topic, 3-4 paragraphs), and one for a revision (revise the existing essay to address the given feedback, still 3-4 paragraphs). Both live inside the same function, branching on whether previous_feedback was passed in.

2 Write the critic agent's prompt

critic_agent() should ask for 2-3 specific, actionable pieces of feedback — not a rewrite of the essay. Focus the critic's attention on clarity, accuracy, impact, and engagement, matching the four dimensions named in Part 3 of the lesson.

3 Finish the loop

multi_agent_loop() already tracks drafts, feedback_rounds, and final_essay in its result dict. Make sure the loop calls critic_agent() on the current draft, stores the feedback, then calls writer_agent() with that feedback to produce the next draft — for num_revisions rounds.

🐞 Task 4 — Debug the Code

A teammate's critic prompt reads: "Read this essay and make it better: {essay}". In testing, the critic keeps returning a full rewritten essay instead of feedback, so the writer's revision step ends up revising a revision instead of responding to actual critique. Explain why this prompt causes that behavior, and rewrite it so the critic reliably returns feedback only.

buggy_critic_prompt.py 
# Bug: "make it better" is an instruction to IMPROVE the essay directly,
# which a capable model will happily do by rewriting it -- there's no
# instruction telling it to return feedback INSTEAD of a rewrite, and no
# constraint on format (e.g. "2-3 bullet points") to make a rewrite an
# awkward fit for the requested output shape.
prompt = f"Read this essay and make it better: {essay}"

Checking your work There's no automated grader here — live model output varies run to run. What matters is the structure: does the critic's response read like feedback (a short, specific list of issues) rather than a rewritten essay? Does the writer's revised draft visibly respond to that feedback rather than just producing a slightly different essay on the same topic? Compare your prompts against solution.py once you've made a genuine attempt.
