Session 6.1 Exercises 25 min, hands-on

Exercises: Wrap an LLM Call in a Flask Service

Build a real, running /ask HTTP service around an LLM-calling function — the exact pattern from this session: an entry point that handles requests, config read from the environment, and no crashes on a malformed request. This is the Core path build.

How to run these Install Flask with pip install flask, then run python3 starter.py. In a second terminal, send it a request: curl -X POST http://localhost:5000/ask -H "Content-Type: application/json" -d '{"question": "What is RAG?"}'
Free/open path — no API key required call_llm() is a mock function by default, so the entire exercise works with zero API cost and no key needed — you're practicing the service-wrapping pattern, not the model call itself. Want to call a real model? Set ANTHROPIC_API_KEY in your environment and swap in the real API call shown commented-out inside call_llm().

The task

Open starter.py. Two pieces are missing, marked # TODO 1 and # TODO 2.

1 Read the model name from the environment

Set MODEL_NAME using os.environ.get("MODEL_NAME", ...) with a sensible default — do not hard-code the model name directly inside call_llm(). This is Change 2 from the lesson: configuration that isn't hard-coded.

2 Validate the request and never let it crash

Inside the /ask route, get the JSON body and check that a non-empty "question" field is present. If it's missing, return a JSON error body with a 400 status — do not let a missing field raise an unhandled exception. If it's present, call call_llm(question) and return the answer as JSON.

🐞 Task 3 — Debug the Code

A teammate wrote this version of the route. It looks reasonable, but sending curl -X POST .../ask with no body at all (not even {}) crashes the process with a 500 and a raw stack trace instead of a clean 400. Find the bug and fix it.

buggy_ask_route.py 
@app.route("/ask", methods=["POST"])
def ask():
    data = request.get_json()  # returns None if the body is empty/missing
    question = data.get("question", "")  # .get() on None crashes with AttributeError
    if not question:
        return jsonify({"error": "question is required"}), 400
    answer = call_llm(question)
    return jsonify({"answer": answer})

Hint: request.get_json(silent=True) returns None instead of raising when the body is missing or not valid JSON — check for that None case (if not data or not data.get("question"):) before calling .get() on it.
