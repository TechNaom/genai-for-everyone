Session 6.4 Exercises 15 min, hands-on

Exercises: Structured Logging & Stats

Add structured logging to a small GenAI service and turn that log into real aggregate numbers — the exact habit that turns "I think it got worse" into "I checked." This exercise is fully self-contained: it simulates a service call with mock_service_call() rather than requiring a real running Flask app from an earlier session, so it needs no API calls, no paid keys, and nothing else to have been built first.

How to run these You'll need Python 3 installed (check with python --version). Download starter.py below, then run it from a terminal with python starter.py. It raises NotImplementedError until you've filled in the functions.
starter.py solution.py (reference)

The task

Open starter.py. It defines a mock service call, an empty REQUEST_LOG, and a GOLDEN_DATASET for later. Four functions need implementing — the first two are this session's Core path.

1 Log every request, consistently

Implement logged_call(user_input): call mock_service_call, then append one log entry to REQUEST_LOG containing input, output, latency_ms, input_tokens, and output_tokens — the same five fields, every single call, no exceptions.

2 Build the stats summary

Implement print_stats(): using REQUEST_LOG, print total requests, average latency, and total tokens (input + output). This is your service's /stats-equivalent — a real number computed from logged data, not a guess.

3 Bonus: log feedback

Implement log_feedback(request_index, thumbs_up): append {"request_index": ..., "thumbs_up": ...} to FEEDBACK_LOG. This is a warm-up for the fuller feedback endpoint you'll build in the Pro-path project.

4 Bonus: check for drift

Implement check_drift(score_fn, threshold=0.8): re-score GOLDEN_DATASET using score_fn, compute the pass rate, print it against the threshold, and return True/False. Another preview of the Pro-path project's drift check, at smaller scale.

🐞 Task 5 — Debug the Code

A teammate's version of print_stats() crashes with a ZeroDivisionError the first time anyone calls it right after starting the service, before a single request has come in. Find the bug and fix it so an empty log prints a friendly message instead of crashing.

buggy_stats.py 
def print_stats():
    total = len(REQUEST_LOG)
    avg_latency = sum(r["latency_ms"] for r in REQUEST_LOG) / total  # crashes when total == 0
    print(f"Total requests: {total}")
    print(f"Average latency: {avg_latency:.0f}ms")
