# Mock Interview Question Bank

## System design questions (15 minutes each)
1. Design a GenAI feature that helps new employees find answers in company documentation.
2. Design a system that summarizes long customer support call transcripts for a manager dashboard.
3. Design a feature that drafts personalized outreach emails for a sales team.

## Live debugging questions (15 minutes each)
1. A RAG pipeline retrieves the right documents but the final answer still ignores them and hallucinates. What's your diagnostic process?
2. An eval report shows 60% accuracy on a golden dataset, down from 90% last month, with no code changes. What do you check first?
3. A structured-output prompt asking for JSON sometimes returns valid JSON and sometimes returns JSON wrapped in explanatory prose. How do you fix this reliably?
