# Exercise — Session 1.1: What GenAI Actually Is (and Isn't)

## The AI Capability Map

**Goal:** Build the habit of classifying any "let's use AI" request before writing a single line of code.

### Instructions

1. Open `capability_map.py`
2. For each of the 12 scenarios in the `SCENARIOS` list, fill in:
   - `category`: `"predictive"` or `"generative"`
   - `io_description`: one sentence describing input → output
   - `example_tool`: a real tool/product that does this
3. Run the script — it will print a formatted table and flag any scenario you haven't filled in yet.
