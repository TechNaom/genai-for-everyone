# Exercise — Session 7.1: Capstone Kickoff

## Overview

Write a one-page capstone proposal, and run a scope-checker script against it that flags common vagueness problems before you show it to anyone else.

- **Core path:** Fill in `proposal_template.md`, then get it passing the checks in `starter.py`
- **Pro path:** Write two competing proposals (narrow vs. ambitious) for the same problem and justify your pick in writing

## Setup

```bash
pip install -r requirements.txt  # no extra deps needed for this exercise
```

## Free/open path

This exercise is pure writing plus a small Python checklist script — no API calls, no cost.

## Optional paid-API path

Not applicable — this session is about scoping, not building.

## Starter code

1. Copy `proposal_template.md` and fill it in for your own capstone idea.
2. Run `python3 starter.py your_proposal.md` to check it against common vagueness red flags (missing numbers in success criteria, filler phrases like "everything"/"anything", no explicit non-goals section, etc.)
