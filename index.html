A course that only teaches "here's a prompt template" leaves you unable to debug why your RAG pipeline retrieves the wrong document, or why your agent loops forever. This course is built artifact-first: every session produces something you run, break, and fix — a prompt, an embedding search, a tool-calling agent, an eval harness, a deployed endpoint — so the concept sticks because you built it, not because you read about it.

How to use this course

  • Read the lesson, take the quiz, do the exercises, then build the week's hands-on artifact — in that order.
  • Every quiz question has its own Check button, so you get instant feedback without submitting anything or waiting for a grader.
  • Sessions with real Python (embeddings, RAG, tool calling) run right in this browser via an in-page Python playground — no local setup needed to follow along.
  • Running the exercise/solution files locally requires Python 3 — see the README for setup.
  • Each week closes with a Mini Build Day — the one artifact worth putting in a portfolio or talking about in an interview.
